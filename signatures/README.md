# Signatures that distinguish ECOs from black holes

Planned; not started.

Analyse the response library through complementary observables: shifts of the complex mode frequencies (Δω_n = ω_n^ECO − ω_n^BH), damping times, overtones and long-lived trapped modes; echo and recurrence times and amplitude ratios, only where a repeated pulse train is supported by the data; resonance peaks, linewidths and spacings of the spectra; and the phase φ(ω) and group delay τ_g(ω) of the reflection, which can separate models whose reflection magnitudes are similar.
