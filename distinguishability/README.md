# Degeneracies and distinguishability

Planned; not started.

Compute pairwise, noise-weighted mismatches between BH and ECO waveforms and between ECO families, separately for the prompt, ringdown, late and full windows, and map them across the model parameters. The question is which combinations of observables, such as {ω_n, τ_g, T_echo, A_late/A_prompt, φ(ω)}, break the degeneracies between models.
